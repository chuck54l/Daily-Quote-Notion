# Notion Embeds

This repository holds static HTML, CSS, and JS files hosted via **GitHub Pages** to embed custom widgets into Notion cleanly.

## Live Pages & Embed Links

* **Widget 1:** `https://chuck54l.github.io/Daily-Quote-Notion/widget1.html`
* **Widget 2:** `https://chuck54l.github.io/Daily-Quote-Notion/widget2.html`

## How to Embed in Notion

1. Copy the live link above for the desired widget.
2. In Notion, type `/embed` and paste the URL.
3. Click **Embed Link**.
